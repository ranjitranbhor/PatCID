# --- Segmentation: DECIMER-Segmentation (PatCID's choice) ------------------
# decimer-segmentation>=1.5
#
# Two install traps, both worth knowing:
#
# 1. Its metadata caps tensorflow at <=2.15.1, and TensorFlow has no CPython
#    3.12 wheel below 2.16 — so on Python 3.12 pip reports
#    ResolutionImpossible across every decimer-segmentation version.
#    Work around it with --no-deps plus its real dependencies:
#      pip install --no-deps decimer-segmentation
#      pip install scikit-image opencv-python matplotlib IPython PyMuPDF \
#                  numba scipy requests pillow
#
#    Do NOT try to satisfy the cap by pinning numpy<2: numpy only supports
#    Python 3.13 from 2.1, so on 3.13 there is no wheel and pip compiles
#    numpy from source into a build that predates the interpreter.
#
# 2. The cap is really a proxy for numpy<2, because the package touches
#    np.VisibleDeprecationWarning (removed in numpy 2.0). That is its ONLY
#    numpy-2 incompatibility, and the single use is a cosmetic
#    warnings.filterwarnings call. structure_finder/compat.py restores the
#    attribute before importing the package, so numpy 2 works. Verified on
#    numpy 2.1.3 + TensorFlow 2.19.1: imports and builds the Mask R-CNN.
